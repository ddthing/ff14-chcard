# FF14 Character Card Generator 🌟

> 파이널 판타지 14(FFXIV) 모험가를 위한 고품질 프로필 카드 생성기입니다. 브라우저에서 바로 아름다운 프로필 카드를 디자인하고 고화질 이미지로 저장할 수 있습니다.

## 🚀 Features (주요 기능)

- **🎨 풍부한 디자인 시스템**: 14종의 한국어/영어/일본어 고품질 웹 폰트 지원 및 커스텀 테마(HEX 색상) 지정 가능.
- **🛡️ 모든 직업 지원**: 최신 확장팩을 포함한 전 전투직 및 제작/채집(DoH/DoL) 직업 레벨 설정.
- **✨ 스마트 스티커 엔진**: 피그마(Figma) 수준의 분리형 핸들을 도입해 완벽한 크기 및 회전 제어, 키보드 세밀 조작(Nudge) 지원.
- **⚡ 100% 클라이언트 사이드 렌더링**: 사용자의 이미지는 외부 서버로 전송되지 않으며, 모든 처리가 브라우저 내부에서 안전하게 이루어집니다.
- **🌍 다국어 완벽 지원 (i18n)**: 한국어, 영어, 일본어 실시간 번역 지원.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Image Processing**: html-to-image (Canvas)

## 📦 Getting Started (설치 및 실행)

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 프로덕션 빌드
npm run build
```

## 🔒 Security & Privacy
본 프로젝트는 **서버리스(Serverless) 정적 웹사이트**입니다. 사용자가 업로드하는 캐릭터 스크린샷이나 입력한 개인정보는 일절 수집되거나 서버에 저장되지 않으므로 안심하고 사용할 수 있습니다.
