# 🎮 FF14 캐릭터 카드 생성기 (FF14 Character Card Generator)

![FF14 Character Card Generator](https://ff14-chcard.pages.dev/og-image.png)

파이널 판타지 14(Final Fantasy XIV) 플레이어를 위한 고퀄리티 캐릭터 프로필 카드 생성기입니다. 클릭 몇 번으로 나만의 예쁜 캐릭터 카드를 만들고 이미지로 저장해 보세요!

[👉 지금 바로 만들기](https://ff14-chcard.pages.dev/)

---

## ✨ 주요 기능 (Features)

- **🎨 세련된 디자인**: 깔끔하고 모던한 UI로 최상의 사용자 경험을 제공합니다.
- **📱 완벽한 모바일 최적화**: 스마트폰에서도 불편함 없이 카드를 만들고 저장할 수 있습니다.
- **🌐 3개 국어 지원**: 한국어, 영어, 일본어를 완벽하게 지원하며 실시간으로 언어를 변경할 수 있습니다.
- **🖼️ 실시간 미리보기 & 편집**: 정보를 입력하는 즉시 카드가 업데이트되며, 이미지 드래그 및 크롭 기능을 통해 캐릭터 사진을 완벽하게 배치할 수 있습니다.
- **🌈 커스텀 컬러 & 폰트**: 나만의 포인트 컬러와 다양한 폰트를 선택하여 개성을 표현하세요.
- **💾 원클릭 이미지 저장**: 버튼 하나로 고화질 PNG 이미지를 즉시 내려받을 수 있습니다.

---

## 🚀 사용 방법 (How to Use)

1. **기본 정보 입력**: 캐릭터 이름, 서버, 주 직업 등을 선택합니다.
2. **이미지 업로드**: 내 캐릭터 스크린샷을 업로드하고, 미리보기 화면에서 드래그하여 위치를 조정합니다.
3. **직업 레벨 설정**: 전투, 제작, 채집 직업의 레벨을 입력합니다. (일괄 만렙 설정 가능!)
4. **스타일 커스텀**: 플레이 스타일 태그를 선택하고, 원하는 폰트와 포인트 컬러를 지정합니다.
5. **저장하기**: '이미지 저장' 버튼을 눌러 나만의 카드를 완성합니다!
