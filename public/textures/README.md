# Card material textures

These paper and print-ink material images were generated for the character card. They are not physical paper scans. The original assets from the unavailable workspace could not be recovered, so these are newly generated replacements serving the same design purpose.

- cotton-paper.webp: generated white cotton paper, optimized to 768 × 768, WebP quality 84.
- print-ink.webp: generated fine ink particulate texture, optimized to 256 × 256, WebP quality 84.

Use real DOM background layers behind type and inside masked SVG glyphs so PNG export embeds the images. Photos and text remain untextured. Forced-colors mode hides decorative material layers.
