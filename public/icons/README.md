# Job icon sources

BST.svg uses a monochrome path traced from the actual Beastmaster game glyph (asset ui/icon/062000/062843_hr1.tex, retrieved via XIVAPI). The tile background and separate border were removed before tracing the dark glyph. This is a path-only SVG, not an embedded raster image and not an SVG served directly by XIVAPI. Game job icon imagery belongs to SQUARE ENIX.

Asset source: https://v2.xivapi.com/api/asset?path=ui/icon/062000/062843_hr1.tex&format=png
